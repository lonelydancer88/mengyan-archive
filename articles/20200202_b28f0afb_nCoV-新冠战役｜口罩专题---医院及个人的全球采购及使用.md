**01.**

**疫情医院需要什么口罩**

一句话回答：一线疫情医护人员需要使用 **医用防护口罩** 和 **医用外科口罩**。

1.1 科普

**划重点：不是所有的 N95 都是一线医用防护口罩！**

“N95”或“KN95”口罩只是统称，意为对非油性颗粒物（如粉尘、微生物、漆雾等）过滤效率达到 95% 以上；**N95 口罩不等于一线医用防护口罩！**

1.2 一线医用口罩需要满足哪些必要条件？

颗粒过滤度（N95）和 液体防护指标，两项必须同时满足！液体防护指标即**「抗合成血液穿透测试」**是大家经常忽视，但一线医用必须满足的指标！后续有具体辨别方法

**为什么？**

肺炎病毒可以通过近距离飞沫和亲密接触传播；一线医护，特别是给确诊病人进行吸痰、插管等操作时，会高密度暴露在飞沫、或血液喷溅中，因此口罩除了颗粒过滤系数 >= 95% 外，还需满足特定的流体阻力，即「抗合成血液穿透测试」。

**不合规的口罩在不知情的状况下给一线战士也有危害性，白衣天使们自己也注意辨别。**

1.3 目前医院对外求助的口罩资源类别

（1）医用防护口罩，即医用 N95 口罩

（2）医用外科口罩

（3）普通防护口罩

（4）一次性医用口罩

疫情医院的一线医护人员必须佩戴（1）或（2），后文也将着重介绍。

**02.**

**医用防护 N95 口罩**

**（有体液喷溅风险的环境中）**

2.1 国内货源说明

1. **必须满足国标 GB19083-2010（该国标含有流体阻力指标 >= 80mmHg）**

2. **必须不含呼气阀**

注：常见的 GB2626-2006 N95 或 N99 口罩，无法阻隔血液、体液和飞沫喷溅，**一线医护不可用带有呼气阀**（只能保证佩戴者安全，对周围人员没有防护作用）的口罩，**更是不可用于医院！**

**国内医用防护口罩常见款推荐**

3M 1860(S)/1870/9132 可以, **3M 1860 为一线员工最标配！**除了这几款，其它 3M 款基本不行。

**供应商资质验证**

需提供工商营业执照，医疗器械注册证，医疗器械生产许可证，第三方检测报告等

**目前国家高效统筹调配了绝大部分国内合格生产线，捐赠者在国内接触货源时需要格外慎重，谨防假货，谨防不合标准。**

2.2 海外货源说明

|  | 指标1: 颗粒过滤度 | 指标2: 合成血液穿透性 |
| --- | --- | --- |
| 美标    （美国） | NIOSH N95 以上（一般为 N95 或 N99） | CDC认证的 fluid resistant（商品说明书中寻找关键字 ）    或者 ASTM F1862 level 1-2-3 均可 |
| 欧标 | FFP2 或 FFP3 | Type IR 或 Type IIR |

* 美标、欧标商品必须**同时满足**上表中的**指标 1**和**指标 2**

* 日标需满足下文中的（1）或（2）

（1）明确写明「サージカルＮ９５レスピレーターとして液体防護性があり、血液を含む液体等に有用」

（2） 符合人工血液不浸透性　80mmHg以上，以及 ΔＰ（呼吸抵抗）＜35mmH2O **必须不含呼气阀**

**供应商资质验证**

提供产品说明书，符合当地市场对应标准，正规的收据或电子凭证等

其他小语种区域，一定注意：

（1）过滤效率（PFE）>= 95%

（2）不含呼气阀

（3）流体阻力防血液、飞沫，该参数指标 >= 80mmHg（可以按照该数据的单位在外包装中找寻）

**再次强调：不合规的口罩给一线战士也是害了他们，请医生们自己也注意辨别！**

**03.**

**医用外科口罩**

**（有体液喷溅风险的环境中）**

3.1 国内货源说明

灭菌级，必须满足国内医药行业标准 **YY 0469-2011**(印在每只独立外包装上）

确认可用 Winner 稳健医疗 [注意看是否标注符合 **YY0469**]

[图片]

3.2 海外货源说明

**美标**

ASTM F2100-11 标准下满足 level 2 或者 level 3（表述方式也可为 level moderate, level high）

[图片]

**欧标**

EN 14683 下测试满足 Type IR 或者 Type IIR 均可

**全球通用核心指标（重要性 1 > 2 > 3）**

1. 细菌过滤效率（BFE）过滤 >= 95%, fluid resistant >= 120mmhg

2. 灭菌级（Sterile）：Yes；或者 Sterile ：No 但是仍满足 EN14683 或 ASTM F2100-11 等同于满足国内的灭菌标准

3. 虽然国标中没有要求，但最好独立包装，防止交叉感染（也有医院严重缺物资表示整包也可，但独立包装优先）

海外部分符合规格的医用外科口罩

**Spectra** SHIELD-9500

**Halyard Health** PFR P1, 46827, 46828, 46867, 46727, 46728, 46767, 48208, 49207

**供应商资质验证**

提供产品说明书，符合当地市场对应标准，正规的收据或电子凭证等

其他小语种区域，一定注意：

过滤等级 >= 95%；同时流体阻力防血液、飞沫，该参数指标 >= 120mmHg （可以按照该数据的单位在外包中找寻）

**04.**

**二线医护（医院中后台物资供应、物流司机、建筑工人等）的降级选择，合理分级**

4.1 N95 防护口罩

国标满足 GB2626-2006，N95 或 N99 口罩，没有呼气阀

海外满足上文中涉及的 >= 95% 过滤标准（欧标 FFP2 或 3，美国 NIOSH 95 或 99）

**简洁来说：海内外有合格资质生产的N95口罩，只要不含呼气阀，均可支援抗疫的二线战士**

4.2 一次性医用口罩

医药行业推荐标准 YYT 0969-2013
