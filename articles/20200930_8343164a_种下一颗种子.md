# 种下一颗种子

[图片]

头图来源：腾讯公益-苦志育才

一年来，感谢大家的厚爱，每篇文章都能收到不少的打赏。在过去一年，我一共写了 51 篇周报，总打赏金额为 33433.37 元。

依照每年的惯例，我凑了个整，并由我代大家把这些钱，捐给那些努力在把这个世界变得更好一些的人们。

这一次的捐赠，我和有知有行的伙伴们，想选择一个和我们理念相似的项目，能够长期陪伴有需要的人共同成长。

因此，我们制定了这次捐赠的 3 个原则：

1）项目的成立是为了实现某一个长期目标，或者解决某一长期问题，对社会有价值；

2）项目要具备长期运营的能力，能在一段时间内搭建良性运营模式，实现自我造血功能；

3）项目团队一定要热爱这件事情，能长期做下去，和有知有行的理念相符。

同时，我们也希望捐赠的机构可以满足 3 个条件：

1）不踩坑，没有负面；

2）能真的帮助到一些人，落到实处；

3）能追踪，有反馈。

最后，我们选择了「苦志育才」项目。

首先，在办学的六年时间中，这个项目从未出现任何负面，而且办学模式已得到验证，目前已经进入扩展期，具备长期运营的能力；

其次，这个项目利用贫困地区的闲置校舍办学。因此，它的所有募资，不会用于基础设施建设，而是主要用于教职工的薪资，以及孩子们的日常生活开支。此外，苦志育才项目每个月会在公众号公开前一个月的收支情况，捐款能落到实处，可追踪、有反馈。

另外，就我个人而言，我认为我们通过自己的产品，向大众传递的长期、追求内在价值的理念，能够辐射到的，是那些可以通过自己的努力，来让生活变得更好的人群。

但是，一些还没有成长起来的困境儿童，是我们的产品所无法辐射到的，他们还没有能力去通过自己的努力来改变一些生活上的困境，他们需要一个成长的空间。

我们憧憬这样一个世界：在那里，人们通过有知有行的投资赚取合理收益，不因理财而焦虑，更好地专注当下、安心工作、享受生活。

在某种意义上，「苦志育才」项目是我们所憧憬的世界的一个小补丁。

它给了那些困境儿童一个成长的空间，度过他们人生最艰难的时光，成为有能力通过自己的努力去改变生活的青年。绝大多数人从苦志育才学校毕业之后，会进入职高，小部分人会进入高中、大学继续学习深造。

因此，我们选择和「苦志育才」项目站在一起，为打造我们所憧憬的世界，日拱一卒，共同成长。

未来，我们会持续关注它的发展，并和你分享我们的观察。

在今天我们一同种下一颗种子，让我们静静地期待开花结果。
