# 寻找一位合规伙伴

有知有行正在寻找一位能够帮助我们守护有知有行和有知有行用户的合规伙伴。

在有知有行，我们对合规工作的认知是：

- 合规，不仅是对外部要求的遵循，更是我们内心的追求。有知有行的核心价值观是「站在用户一边」，监管要求的目标是「保护投资者的合法权益」，这两者是一致的。落实监管要求，也是在践行我们的核心价值观。
- 我们信赖合规的专业价值。我们热爱学习、研究、讨论法律法规和监管实践，我们不做挂在墙上的制度，我们也在不断地用实际工作说明，合规能够为公司的长期发展和创新创造价值。
- 有知有行的合规工作，是「球队文化」。合规同学会深入了解业务，业务同学会主动思考合规，合规同学就像是守门员，其他同学不论所处的位置是前锋、中锋还是后卫，大家会齐心协力把防守做好。

有知有行是家创业公司。这意味着，我们的合规同学要 cover 很多领域，但也意味着有许多探索空间，有许多从 0 到 1 的事情等待被实现。

以下是具体的工作描述，希望能让你对这份工作有更多的了解。

合规同学的主要工作是：

1. 制定、审核公司的合同、协议及其他法律文件，对公司经营决策、业务方案等提供法律意见；

2. 解读法律法规，协助申请公司经营所需的金融业务资格，与监管部门进行日常联络；

3. 落实合规内控要求，进行合规审核；

4. 对公司日常业务进行合规监控，预警风险，代表公司解决相关的经济纠纷，处理有关仲裁、诉讼。

我们希望你：

1. 拥有较强的责任心、自驱力以及良好的沟通合作能力，能够快速学习新知识并独当一面；

2. 法律专业毕业，国内外院校本科及以上学历；

3. 通过司法考试；熟悉公司法、基金法、合同法、基金销售机构监督管理办法等法律法规；

4. 至少两年以上基金、证券或银行等金融业或律师事务所金融相关工作经验；

5. 专业经验丰富，具有基金业合规风控工作经验或律师资格证书者优先。

工作地点：海南省海口市

有知有行会为你提供一份不错的薪酬，一个优秀公司的股权。在这里，有一群真诚、用心、温暖的伙伴，我们是一个充满好奇、活力、勇气的团队。

有知有行有一份独特的文化，我们追求自由与责任，每一个人可以在这里打造自己的 career，用心做自己。
