# 投资实证这五年：穿越那些历史时刻，和内心的真实感受

欢迎来到「有理有据」。

投资，是科学与艺术的结合。我们理解情绪的重要性，也强调科学的必要性。在这里，我们以问题为起点，用数据还原事实，用轻松易懂的方式解读原理与逻辑。一起拨开问题的迷雾，构建起那些我们在投资中必须要知道的正确常识。

开始做一件事情时，人们往往会高估一个月、一年的变化，

但当你坚持五年、十年，我们又常常低估它带来的变化。

五年足以让一件事慢慢发芽，长成它最真实的样子。

对孟岩来说，五年是持续创业，也是一次真金白银的实盘直播。

2017 年 9 月，孟岩开始记录这个本金 500 万的投资实盘，

他希望用五年时间来证明，普通人也可以在A股获得不错的收益。

五年过去了，这场实盘经历了什么？结果又如何？

有理有据做了一次完整盘点，带你回顾孟岩的五年实盘。

经历了 2018 年的震荡下跌、2019 年的小牛市、2020～2022 年的新冠疫情，

截至 2023 年 3 月 17 日，孟岩投资实盘的年化收益率为 7.14%。

同期，万得全A的年化收益率为 1.53%。

在这场仍在直播的实盘里，A股还会经历什么，未来收益如何，恐怕只有时间知道。

但这并不妨碍我们在A股赚到钱。

五年实盘，收益背后，更重要的是——

这一路相伴，让我们明白长期投资的理念是可行的；

也证明了，投资不一定是轰轰烈烈的，也可以是安心踏实的。

涨跌有伴，有知有行与你一路同行。

💡 **名词解释**

**资金加权收益率：**考虑每笔资金进出的影响，对其进行加权处理的收益率，采用 Modified Dietz 方式计算。计算公式为资金加权收益率 = 累计收益 / 调整后的总资产。其中：（1）调整后的总资产 = 期初总资产 + 合计（单笔现金流的时间权重 * 单笔现金流金额）（2）单笔现金流的时间权重 = 该笔现金流在统计区间的存在天数 / 期间总天数。

**万得全A指数：**由上海证券交易所和深圳证券交易所上市的所有A股组成，以股票在市场上流通的股本（市值），所以万得全A指数更能反映A股整体收益情况。
