# 寻找三位伙伴

[图片]

从有知有行去年12月拿到基金销售资格批复，「尽快上线交易」就是我们和许多用户共同的期待。在经历了繁杂的系统搭建、各种外部机构连通的工作之后，很开心，我们进入了最后的冲刺阶段，伙伴们正在紧张地进行着交易稳定性的测试和服务体验的打磨，很快，具有交易功能的「有知有行」将和大家见面。

在这个令人期待的当下，我想用这篇文章寻找三位新伙伴，帮助有知有行打造更好的交易服务，为用户提供更好的服务体验。这三位新伙伴，分别是：

- 运营清算助理
- 客户服务顾问
- 交易系统开发工程师

对有知有行来说，获取牌照、提供交易功能，是至关重要也充满挑战的，但比这个更重要也更具挑战的，是打造这样一个团队：始终以用户为中心，持续产生新的想法，并一步步把它们变为现实，创造出用户需要的、对用户有价值的服务和体验。有知有行有一份温暖有爱的文化，与此同时，自驱和坚韧，也是我们非常注重的特质，正是这些，帮助有知有行一次又一次地穿越危机，一直去创造对用户有价值的服务。

每个岗位具体的要求和期待，可以看看下面由我的伙伴提供的职位描述。

谢谢你的时间，也欢迎你将这篇文章转发给你认为合适的人。

## 运营清算助理

有知有行的价值观是「站在用户一边」，运营清算，是最终保障用户交易顺利、资金安全的岗位。

有知有行已经有一支专业、负责的运营清算团队。这次招聘的伙伴，不需要已经具有运营清算的工作经验，我们更在意的，是你是否认真、负责、用心。运营清算工作大多有明确的流程，做久了可能像「重复劳动」，容易流于形式。但每一笔交易、每一条数据，都承载着用户的资金和信任，需要用心对待。我们希望你在日常工作中，始终保持连接感，start with why。我们看重你在每一笔交易、每一条数据中，积累起来的思考、认知和应对能力。

我们也期待，你在规范、严谨的同时，保有追求卓越的热度。希望你在完成流程和任务的同时，保持开放的心态，探索提升效率、优化用户体验的可能。

岗位名称

运营清算助理

岗位职责

- 协助运营清算专员完成基金参数录入和数据维护；
- 协助运营清算专员完成基金业务的日常清算工作；
- 协助运营清算专员完成与各个业务合作方的沟通工作；
- 完成其他日常的运营清算工作及公司安排的其他任务。

岗位要求

- 具有良好的职业操守，能够积极参与团队协作，善于沟通，责任心强；
- 具有基金从业资格者优先，具有基金运营清算工作经验者优先，熟悉恒生等第三方基金交易系统者优先。

工作地点：海南省海口市。

## 客户服务顾问

2020 年，我们就为用户服务伙伴工作的空间起了个名字，「三双鞋」。

这个名字引述的是鞋界亚马逊 Zappos 的故事。 当顾客买一双鞋，Zappos 会免费送三双鞋给你试试。我们希望，用这个名字提醒自己，将心注入，用心服务，有知有行与用户的交流不是为了促成短期的交易，而是期待与用户建立并保持长期深度的关系。

岗位名称

用户服务伙伴（客户服务顾问）

岗位职责

- 接听客户来电及在线咨询，专业、高效地解答用户疑问；
- 定期回访客户，了解投资体验，收集并整理服务意见与需求，及时向相关伙伴反馈；
- 受理客户投诉与建议，做好记录、跟进和反馈，确保问题得到及时解决；
- 与其他部门协同合作，共同提升客户服务质量。

岗位要求

- 持有基金从业资格证书；
- 熟悉基金、证券等基础金融知识，了解基金产品的交易规则和市场动态；
- 普通话标准，具备良好的沟通能力、服务意识和亲和力；
- 工作细致耐心，具备较强的抗压能力，善于倾听，能妥善处理客户情绪与突发情况；
- 思维清晰，表达有条理，具备良好的团队合作精神。

工作地点：海南省海口市。

## 交易系统开发工程师

我们不希望按照惯例去思考基金销售服务应该是什么样子。

历经多年努力，有知有行终于获取了为用户提供基金交易服务的宝贵资质。我们希望，站在过去几年积累的认知之上，重新思考，什么样的基金投资服务和体验，是对用户更有价值的。这是一个充满可能性、也充满挑战的旅程。我们期待寻找一位熟悉基金交易系统开发、渴望创新的伙伴，一起开启这场探索。

岗位名称

交易系统开发工程师

岗位职责

- 基金交易系统研发：参与公司基金交易核心系统的设计与开发；基于恒生理财销售 5.0 系统（直销、清算、反洗钱子系统）进行功能优化与扩展开发，负责与恒生等外部系统的接口对接、联调和维护，保障交易流程的准确性与稳定性；业务涵盖基金申购赎回、清算对账、资金划拨等全流程，确保系统的高效性与稳定性。
- 投顾系统建设：在未来自研投顾系统的建设中，主导或参与投顾策略引擎、组合交易执行、风控监控等模块的研发，支撑公司投顾业务快速创新发展。
- 需求分析与架构设计：与产品、业务、运营等团队紧密协作，深入理解基金销售与投顾业务需求，参与系统架构设计、技术方案评审与落地实施。
- 持续迭代与体验优化：以用户价值与使用体验为导向，不断优化系统性能与使用流程，推动技术和产品的持续创新。

岗位要求

- 行业经验：3 年及以上基金、券商或资管行业交易系统研发经验，熟悉基金销售业务流程；有恒生基金交易、清算等系统的开发或对接经验者优先。
- 技术能力：精通 Golang、Java 等至少一种主流编程语言及常用开发框架，熟悉分布式系统设计、微服务架构及高并发系统开发。
- 业务理解：对基金申赎、清算、资金划拨、份额登记等交易流程有深入理解，了解投顾策略与组合交易逻辑者加分。
- 计算机基础：具备扎实的计算机基础知识，包括数据结构、算法、操作系统、计算机网络等，能独立分析和解决复杂技术问题。
- 数据库技能：熟悉 MySQL、Postgres 等关系型数据库，具备良好的数据库设计与 SQL 性能优化能力。
- 创业精神：具备快速学习能力和较强的抗压能力，乐于在节奏快速、强调创新的创业环境中工作，拥有良好的沟通协作能力和团队合作精神。

工作地点：北京 / 海南省海口市。
