# 你好，2.0

[图片]

题图：有知有行窗外

今天，有知有行发布了 2.0 版本。

版本号的第一位数字一旦变化，通常意味着这是我们很骄傲的一次更新。很开心和你分享这份准备已久的喜悦——有知有行的基金交易功能正式上线。

作为第一步，我们先推出了单只基金交易功能。

可能和你熟悉的基金交易平台不同，这个版本没有基金排行榜、没有热点推荐、没有大而全的基金超市、也没有一些成熟平台更便捷的交易功能 …

我们选择做了三件事：

- 从一万多只基金中，按照有知有行的理念和标准，严选出几十只；
- 用我们对基金和投资的理解，重新设计基金产品页面，让信息更清晰、更透明；
- 尝试用心理账户的方式，让投资和生活目标建立更紧密的关联。

基金选择只是投资中的一个环节。真正重要的，还有财务规划、资产配置、仓位控制 … 因此，「基金严选」是为部分进阶投资者提供的一种选择，也是我们愿景途中的一小步。

但我们依然想用这个版本，以及以前的每一个版本，和你分享有知有行对投资的理解：

投资的意义，从来不止是一只基金、一个策略或是一笔交易，而是如何通过投资，让我们过上更好的生活。
